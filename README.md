## English

### 📝 Description

An educational racing game designed to help children practice multiplication tables (1-10) in a fun and engaging way. Players drive a car down a winding road and must collect the correct answers to multiplication problems while avoiding crashes and managing their lives!

### ✨ Features

- 🎮 **Interactive gameplay** - Drive a car using arrow keys, A/D, or touch screen
- 🧠 **Smart Learning** - The game tracks your mistakes and repeats them more often to help you master them
- ❤️ **Life System** - You have 3 lives! A wrong answer doesn't mean "game over" immediately
- ⚡ **Dynamic Difficulty** - Math problems start easy and get progressively harder based on your score
- 🌍 **Visual Biomes** - Environment changes as you progress (Forest, Desert, Cyber Night, and Winter)
- 🎊 **Celebratory confetti** - Visual reward for correct answers
- 🛣️ **Endless winding road** - Procedurally generated path
- 📊 **Progress tracking** - Real-time score, speed, and lives display

### 🎯 How to Play

1. **Goal**: Collect correct answers by driving through blue boxes on the road
2. **Controls**: 
   - Use **← →** arrow keys or **A D** keys to steer
   - **Touch**: Drag your finger on the screen to follow
3. **Rules**:
   - Drive through the box with the correct answer to gain points
   - Hitting a wrong answer or missing both answers costs you **1 life**
   - Driving off the road ends the game immediately!
   - Reach 0 lives and the game ends
4. **Scoring**: 
   - Each correct answer = +1 point
   - Every 5 correct answers = speed increases by 0.3×

### 🚀 Getting Started

Simply open the `index.html` file in any modern web browser. No installation or build process required!

```bash
# Clone the repository
git clone https://github.com/darangonaut/multiplication-race.git

# Navigate to the directory
cd multiplication-race

# Open in browser
open index.html
```

## Česky

### 📝 Popis

Vzdělávací závodní hra navržená tak, aby pomohla dětem procvičovat malou násobilku (1-10) zábavnou a poutavou formou. Hráči řídí autíčko po klikaté cestě a musí sbírat správné odpovědi na příklady z násobilky, přičemž si musí hlídat své životy a zůstat na cestě!

### ✨ Funkce

- 🎮 **Interaktivní hra** - Řiď autíčko pomocí šipek, kláves A/D nebo dotykové obrazovky
- 🧠 **Smart Learning** - Hra sleduje tvé chyby a častěji ti dává příklady, které ti nejdou, abys je lépe procvičil
- ❤️ **Systém životů** - Máš 3 životy! Špatná odpověď neznamená okamžitý konec hry
- ⚡ **Dynamická obtížnost** - Příklady začínají jednoduše a postupně se stávají těžšími podle tvého skóre
- 🌍 **Vizuální biomy** - Prostředí se mění s tvým postupem (Les, Poušť, Kyber-noc a Zima)
- 🎊 **Oslava konfetami** - Vizuální odměna za správné odpovědi
- 🛣️ **Nekonečná klikatá cesta** - Procedurálně generovaná trasa
- 📊 **Sledování pokroku** - Zobrazení skóre, rychlosti a životů v reálném čase

### 🎯 Jak hrát

1. **Cíl**: Sbírej správné odpovědi projetím modrými krabičkami na cestě
2. **Ovládání**: 
   - Použij klávesy **← →** nebo **A D** pro řízení
   - **Dotyk**: Táhni prstem po obrazovce a auto ho bude následovat
3. **Pravidla**:
   - Projeď krabičkou se správnou odpovědí pro získání bodu
   - Projetí špatnou odpovědí nebo minutí obou tě stojí **1 život**
   - Vyjetí z cesty ukončí hru okamžitě!
   - Hra končí, pokud ztratíš všechny 3 životy
4. **Bodování**: 
   - Každá správná odpověď = +1 bod
   - Každých 5 správných odpovědí = rychlost se zvýší o 0.3×
